# Aset Sakuva

Landing page memakai file gambar berikut dari folder `/assets/`. Masukkan file aset asli ke folder ini tanpa mengubah nama:

- `sakuva_icon_transparent.svg`
- `sakuva_logo_transparent.svg`
- `beranda.webp`, `dompet.webp`, `kelola_dan_tambahkategori.webp`
- `manajemendata.webp`, `pengaturan.webp`, `riwayat.webp`
- `tambahtransaksi.webp`, `pengingat_dark.webp`
- `beranda_dark.webp`, `dompet_dark.webp`
- `kelola_dan_tambahkategori_dark.webp`, `manajemendata_dark.webp`
- `pengaturan_dark.webp`, `riwayat_dark.webp`
- `tambahtransaksi_dark.webp`

Aset gambar tidak termasuk dalam file TSX yang dikirim sebelumnya, jadi folder ini disertakan sebagai tempat menaruhnya.
